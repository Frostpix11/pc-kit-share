Исправление 0.2.0: ночная палитра к точным индексам 48-цветного исходника.
Источник — `art/original-day`. Ночной LUT — `art/night-palette.json`.
У лунно освещённых поверхностей и светлых частей стола отдельные рампы.
Никакого ресайза основного рисунка, альфы исходные побайтово. Звёзды и серафим
вырезаны из image_gen: отдельные добавочные слои. 18 исходных + 2 новых = 20.

Пересборка: `python build_assets.py` (Pillow, NumPy; scipy не требуется).
Проверка: `python tests/test_assets.py`. Затем `python install.py`, reload.
Не обновлять assets при включённой сцене частично: сначала отключить плагин,
собрать/проверить, затем установить и включить.

Подпись: `Wallpapers.wallKey()` для новой сцены вне папки релиза не наследует
`perWall[/home/angel/Pictures/AngelOS/06-2004]`. Поэтому сначала использовался
общий sceneDepth=clock и показывался отдельный ReleaseMark. При инициализации
плагин добавляет свои два perWall с sceneDepth=release и параметрами исходного
релиза, только если их ещё нет. Глобальные настройки не меняются.
Исходные z=25, rect=[234,37,80,34], texture_layer=01_sky сохранены; город z=30
перекрывает текст. Реальный runtime подтвердил ReleaseMark.visible=false,
inScene=true; в SceneWall — depthMode=release, исходный rect и z.

`tests/check_runtime.py` требует временный диагностический плагин с
`tests/RuntimeCheck.qml` (не входит в устанавливаемый плагин). Он проверяет
реальные SceneBehind.walls, настройки и IPC. После проверки удалить только
созданный временный каталог. Не оставлять диагностические хуки в core.
Тест меняет light/dark и восстанавливает исходный appearance.mode в finally;
оставляет mode=night. Не запускать при активных действиях пользователя в UI.

Настройки плагина визуально проверены в текущем Persona-оформлении;
проверочные скриншоты удалены после завершения. Переключение всей оболочки на Golden Gate в этой
сессии не проверялось; используются те же штатные сцены и Skin-контролы.
Тест обновления upstream не проводился. Основная копия репозитория чистая;
оболочка, авторские обои, другие плагины и пользовательские данные не патчились.

При смене skin GoldenGate меняет слот обоев с задержкой 400 мс. RoomService
ждёт 650 мс и совпадения themeOf с Skin.mac до сохранения/применения назначения.
При отключении восстанавливает только всё ещё принадлежащие плагину слоты;
при обычном reload snapshot не восстанавливается и не перезаписывается.
