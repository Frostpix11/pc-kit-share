# Комната angelOS — день и ночь

Локальный плагин `angelos-room` 0.2.0. Дневная комната «Летнее утро» автора
MixaDoDs сохранена без изменений; ночная использует тот же исходный рисунок,
точные прозрачные контуры и скрытые области, с отдельной ночной палитрой.
За окном — маленький серафим с медленным парением.

## Использование

**Проект завершён 2026-10-28. Пользователь подтвердил итоговую версию 0.2.0.**
Плагин установлен и включён. Выбран режим **Ночь**.
В настройках плагина «Комната — день и ночь» доступны:

- **День** — исходные дневные обои автора.
- **Ночь** — ночная версия независимо от темы интерфейса.
- **Авто** — следует дневному/ночному режиму angelOS, включая его расписание.

Управление из терминала:

```sh
qs -c angelos ipc call angelos-room mode night
qs -c angelos ipc call angelos-room mode day
qs -c angelos ipc call angelos-room mode auto
qs -c angelos ipc call angelos-room state
```

Отключение через список плагинов возвращает прежние обои и прежние назначения
по экранам/рабочим столам. Если во время работы плагина пользователь выбрал
другой фон, отключение его не заменяет. Перезагрузка оболочки сохраняет режим
и резервное назначение, не записывая ночную сцену вместо исходного фона.

## Установка и обновления

```sh
cd /home/angel/Projects/AngelOS-Room
python install.py
qs -c angelos ipc call angelos reload
```

Установщик плагина **не** меняет код Quickshell, исходный репозиторий angelOS,
папку авторского релиза, настройки Typer или пользовательские заметки.

- Плагин и обе сцены: `~/.config/angelos/plugins/angelos-room/`.
- Ссылки для штатного сканера сцен: `~/Pictures/AngelOS-Room/day` и `night`.
- Режим/прежний фон: `plugins.data.angelos-room` в настройках angelOS.
- Собственные настройки глубины: `wallpaper.perWall` для двух новых сцен.
- Резервные копии установок: `~/.local/state/angelos-room/backups/`.

Это пользовательский плагин вне заменяемой папки оболочки. По текущему коду
установщика обычное обновление angelOS его не перезаписывает; переносить патч
после каждого обновления не требуется. Будущая несовместимость Plugin API или
формата сцен может потребовать обновить сам плагин. Реальное обновление upstream
ради проверки не запускалось.

В `dist/angelos-room-0.2.0.zip` — самостоятельная папка плагина со сценами
и лицензией авторского исходника. На другой машине также нужно создать ссылки
`~/Pictures/AngelOS-Room/{day,night}` на соответствующие папки `scenes` плагина.

## Рисунок и движение

Логический холст автора 656×376, видимая область 640×360 с запасом 8 px.
Мы сохраняем эту сетку: увеличение разрешения с интерполяцией ухудшило бы
пиксельный рисунок. Все 18 исходных слоёв, их цветовые индексы, альфа, z,
параллакс, корни ветра, attachment и hold-маски сохранены. Ночная палитра
описана в `art/night-palette.json`; окна подсвечены по существующим пикселям
окон в слое города. Дополнительно выделены звёзды и 16 кадров серафима.
Движение, пауза и перекрытие виджетов — штатный SceneWall angelOS.

Название релиза находится в исходном `depth_text`: z=25, rect=[234,37,80,34],
перед небом и за домом z=30. Плагин задаёт `sceneDepth=release` только своим
двум сценам, поэтому штатная отдельная угловая ReleaseMark скрывается.

## Проверки

```sh
python tests/test_assets.py
```

Шесть тестов проверяют неизменённый день, альфы, все исходные пиксельные
индексы, совмещение reference со слоями, кадры серафима и штатные scene-list,
scene-depth, scene-hold. В работающей системе проверены день при тёмной теме,
ночь, авто при light/dark, отключение/включение, reload, сохранение исходного
фона, 20 загруженных слоёв без Image.Error, flexReady и смена кадров серафима.
Результаты — `tests/runtime-results.json`. Временный диагностический плагин
после проверки удалён.

Готовая картинка: `art/night-composite.png`. Компактные исходники звёзд и
серафима — `art/sources/`; запросы и происхождение image_gen — `art/provenance/`.
Промежуточные атласы, ранние превью, проверочные скриншоты и тестовые кэши
удалены после завершения. Пересборка из сохранённых исходников побайтово
совпала с одобренным плагином; все шесть тестов повторно прошли.
Список уборки — `art/provenance/cleanup-20261028.json`. Резервные копии сохранены.
