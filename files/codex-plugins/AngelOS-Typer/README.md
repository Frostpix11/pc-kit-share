# AngelOS Typer

Небольшой графический редактор текста и Markdown для angelOS.
Привычные сочетания с Ctrl, дерево папки и вкладки. Интерфейс 0.3 оформлен
по мотивам Страты: компактные панели, цветные значки Pixora из системной темы,
палитра angelOS. Заголовок и кнопки окна рисует оконный менеджер, как у терминала
(проверено в Desktop-режиме angel-niri).
Приложение работает отдельно от Quickshell; плагин добавляет быстрые заметки,
пункты меню рабочего стола и команды в лаунчер.

## Иконка

Для Typer нарисована оригинальная иконка блокнота с сиреневым пером на сетке 16×16,
с палитрой и ступенчатыми контурами установленного Pixora.
Исходник — [SVG](assets/local.angelos.Typer.svg). Установщик размещает её в hicolor
и установленных слоях Pixora/angelOS, обновляет кэши и создаёт PNG-размеры 16–256,
если доступен rsvg-convert. Остальные значки темы не изменяются.

## Начать работу

Запустить **AngelOS Typer** из меню приложений или открыть `.txt` / `.md` в Страте.
В меню Typer выбрать **Открыть папку**, чтобы получить дерево документов слева.

- **Очистить дерево** внизу слева убирает текущую и недавние папки. Это состояние
  сохраняется после перезапуска; файлы на диске, вкладки, черновики и избранное остаются.
- Один клик по файлу — временная вкладка. Двойной клик или редактирование оставляет её.
- Выделить текст → правая кнопка → **Форматирование**: жирный, курсив, зачёркивание,
  код, ссылка, заголовки, списки и цитата.
- Для `.txt` Typer предлагает новую Markdown-копию: исходный текст не меняется.
- **Просмотр** переключает Markdown между исходным текстом и оформленным документом.
- **Оглавление** показывает заголовки, **Только текст** скрывает боковые панели.
- Избранное — в меню приложения. Текущую папку можно закрепить через настройки.
- Орфография: русский и английский. Правое меню ошибочного слова содержит исправления.
- Иконка бумажки на панели открывает маленькое окно заметки. «Прикрепить» или
  Ctrl+Enter оставляет её на рабочем столе; тяни за любую часть. Три быстрых
  левых клика убирают бумажку, «Вернуть» в окне ввода восстанавливает её.
- В лаунчере можно ввести `typer` и выбрать редактор или маленькую заметку.
  [Подробности плагина и его обновления](plugin/README.md).

## Сочетания

| Действие | Клавиши |
| --- | --- |
| Новый текст | Ctrl+N |
| Открыть файл / папку | Ctrl+O / Ctrl+Shift+O |
| Сохранить / сохранить как | Ctrl+S / Ctrl+Shift+S |
| Найти файл по имени | Ctrl+P |
| Найти / заменить в файле | Ctrl+F / Ctrl+H |
| Поиск по всей папке | Ctrl+Shift+F |
| Закрыть вкладку | Ctrl+W |
| Следующая / предыдущая вкладка | Ctrl+Tab / Ctrl+Shift+Tab |
| Markdown-просмотр | Ctrl+Shift+M |
| Дерево файлов | Ctrl+B |
| Режим сосредоточения | F11; Esc возвращает панели |
| Отменить / повторить | Ctrl+Z / Ctrl+Shift+Z |

Вертикальная прокрутка тачпада работает штатно. Горизонтальные жесты переключают
вкладки, если хост/VM передаёт их в Linux. Их можно отключить в настройках.
Физический тачпад в этой VM проверяет пользователь; автоматический тест не заменяет
такую проверку. Сочетания редактора учитывают латинскую группу клавиатуры.

## Сохранение и черновики

Сохранение файлов — вручную. Черновик записывается после короткой паузы в наборе
(650 мс), восстанавливается при следующем запуске. При закрытии изменённого текста
Typer предлагает сохранить, отказаться от изменений или вернуться к работе.
Открытые сохранённые документы и позиция курсора восстанавливаются при запуске.

Запись файлов атомарная: сначала временный файл в той же папке, затем замена.
Права существующего файла сохраняются, символьная ссылка ведёт к прежней цели.
Если файл изменила другая программа, Typer предлагает копию или явную перезапись.
Исходные переводы строк и UTF-8 BOM / UTF-16 сохраняются. При редактировании файла
со смешанными переводами строк они приводятся к первому обнаруженному виду.

Состояние и черновики: `~/.local/state/angelos-typer/` (приватные файлы).
Настройки: `settings.json` в этой же папке.

## Установка и обновление локальной версии

Зависимости: Python 3, python-gobject, GTK 4.10+, libadwaita 1.6+, GtkSourceView 5,
Hunspell. На этой машине они уже установлены. Русский и английский словари
из официальных подписанных пакетов Arch Linux ARM находятся в `assets/dictionaries`.
Там же — сведения о происхождении и лицензии словарей; код Typer — MIT.

```sh
cd /home/angel/Projects/AngelOS-Typer
python install.py
```

Установка пользовательская, без sudo. Копии приложения находятся в
`~/.local/share/angelos-typer/app`, запускатель — `~/.local/bin/angelos-typer`,
плагин — `~/.config/angelos/plugins/angelos-typer`.
Редактор назначается для `text/plain`, `text/markdown`, `text/x-markdown`.
Для установки без смены ассоциаций: `python install.py --no-default`.
Обновить только редактор, сохранив установленный плагин бумажек:
`python install.py --app-only --no-default`.
Старые ассоциации и предыдущая установка сохраняются в
`~/.local/state/angelos-typer/install-backups/<дата>/`.

После обновления приложения закрыть и снова открыть Typer. После установки нового
плагина перезагрузить оболочку: `qs -c angelos ipc call angelos reload`.
Исходный репозиторий AngelOS-Dotfiles установщик не меняет. Обновление оболочки
не должно удалять пользовательские приложение, плагин и черновики: они находятся
вне каталога кода оболочки. При будущих изменениях API плагинов совместимость
проверяется отдельно.

Правка обводки стороннего privacy-eye хранится в
`~/Documents/angelOS-bugs/privacy-eye-hover/`; обновление самого privacy-eye
может её заменить. Прежние исправления Genie и Win+D находятся в коде оболочки
и после обновления проверяются по `~/Documents/angelOS-bugs/PATCHES.md`.

## Проверки

```sh
python -m unittest discover -s tests -v
python tests/ui_smoke.py
python tests/ui_close.py
```

Первый набор проверяет реальную запись, отказ при внешних изменениях и восстановление
черновиков. Второй запускает настоящий GTK-интерфейс с временными файлами и проверяет
вкладки, форматирование/undo, сохранение, черновики, поиск, тему и меню.

## Границы версии 0.3

Это редактор обычного текста и Markdown, а не RTF/Word. Просмотр поддерживает
заголовки, выделение, списки, цитаты, ссылки и блоки кода; сложные таблицы и изображения
пока отображаются исходной разметкой. Текстовые файлы — до 20 МБ, поиск по папке —
до 10 000 файлов, содержимое отдельных файлов до 2 МБ, до 200 совпадений.
Не-UTF текст без BOM требует предварительного перевода в UTF-8; бинарные файлы
не открываются как текст. Подсветка орфографии проверяет первые 150 000 символов.
Приложение предназначено для Linux/angelOS, отдельной версии macOS пока нет.

Ничего автоматически не публикуется на GitHub.
