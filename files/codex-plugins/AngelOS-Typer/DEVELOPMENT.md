# Состояние проекта

2026-10-28: пользователь одобрил интерактивный макет и поручил написать приложение
и интегрировать его с angelOS. Ключевое дополнение: форматирование выделенного
текста должно находиться в контекстном меню по правой кнопке.

Исходные ответы анкеты — `requirements-survey.json`. Поле
`implementation_authorized: false` относится к моменту заполнения анкеты;
позднейшее явное поручение пользователя разрешило разработку и установку.

## Сделано

- Самостоятельное приложение Python / GTK 4 / libadwaita / GtkSourceView 5.
- Работа с настоящими файлами; файловое дерево; временные и постоянные вкладки.

- Поиск и замена; фоновый поиск по папке и поиск файла по имени.
- Избранное, недавние папки, оглавление, режим сосредоточения.
- Русская и английская орфография; исправления в контекстном меню.
- Настройки размера текста и жестов; управление с Ctrl на клавиатуре Mac.
- Адаптация поля редактора к экспортируемой палитре angelOS, включая тёмный фон.

## Свободное движение, глубина и Pixora (2026-10-28)

Редактор 0.2.0, плагин 0.3.0. Подтверждена причина странного движения: generic
DesktopWidgetHost использует settledPlace во время каждого движения. Он округляет
координаты к сетке и отталкивает от других виджетов. В фактическом QtTest-трейсе
ожидаемая x=69 получалась 64, x=74 — 80, x=104 — 112; y=567 становилась 560.
Бумажки теперь задают host.x/y локальными Binding с прямыми координатами указателя,
сохраняют их без snap, учитывают начальный параллакс и ограничены краями экрана.
Настройки общей сетки и код ядра оболочки не менялись.

Повторный QtTest-трейс с шагами 5,10,20,40,65,90 пикселей подтвердил точное
совпадение actual/expected на каждом шаге. Бумажкам задана стандартная глубина deep;
через реальный WidgetDepth проверены on=true, placed=true, covered=true, plane=21.5.
При покое их закрывает передний план, при движении они поднимаются как другие виджеты.
Значок панели уменьшен до видимой высоты 9 art pixels, как соседние стандартные значки;
увеличение при наведении убрано, размеры клетки приведены к обычным кнопкам.

Нарисована новая оригинальная SVG-иконка Typer на 16×16 по локальным референсам
Pixora: голубой блокнот и сиреневое перо, ограниченная палитра, целые пиксели.
Установлена в текущую angelos-folders-b, Pixora и fallback hicolor; PNG 16,32,48,
64,128,256. GTK lookup подтвердил новый файл в активной теме. Кэши обновлены,
оболочка перезапущена. Настройка пользователя tintTasks=accent сохранена, поэтому
неактивные значки приложений на панели могут быть тонированы, как остальные.

Проверки: 8 core tests, GTK smoke test, Node-тесты тройного клика и непрерывного
движения, реальный QtTest-трейс, depth covered, визуальный просмотр SVG и панели.
Установленная сборка и настройки сохранены; временные IPC-методы удалены также из
резервных копий. Backup установки: install-backups/20261028-011302.

## Редактор 0.3.1 — закрытие с первого нажатия (2026-10-28)

Пользователь заметил: пустой Typer закрывался только со второго нажатия.
Воспроизведено настоящим win.close() в цикле GTK с временным состоянием:
после одного вызова окно оставалось в app.get_windows(). Причина — обработчик
close-request при синхронном обходе неизменённых вкладок рекурсивно вызывал
win.close(), а затем возвращал True и блокировал исходное закрытие.
Разрешённое закрытие теперь выполняется через GLib.idle_add после выхода
из обработчика. closing_window блокирует повторные запросы, пока показан
диалог сохранения; при отмене флаг сбрасывается.

Новый tests/ui_close.py: пустой документ, сохранённый файл, отмена и повторное
закрытие с отказом от изменений, сохранение изменённого файла. Ответы диалога
проверены clicked настоящих GTK-кнопок; проверяются закрытие и содержимое файла.
Проверка пустого окна падает до исправления, все 4 сценария проходят после;
общий GTK smoke test также прошёл. Установлен только редактор, плагин сохранён.
Backup: install-backups/20261028-104218. Обновлённое приложение запущено.
