# Наши обои

Свои живые сцены для angelOS в формате автора (`angelos.layered-scene.v1`). SceneWall рисует их так же, как обои релизов. Картинку рисует Codex, всё остальное собирается кодом.

`./install.sh walls` ставит в `~/Pictures/Celestia/` ссылку на каждую сцену отсюда и включает ей мягкую реакцию на музыку.

## «Тихая гавань» (`tihaya-gavan/`, 13.11.2026)

Горное озеро, домик с окошком, мостки с фонарём, лодка, сосны. Пиксель-арт 320×180 (×6 на 1080p, ×12 на 4K), 64 цвета, палитра в тон скина serp.

| Что | Как |
|---|---|
| Время суток | день; сумерки 20–21 ч; ночь с луной и 40 звёздами; рассвет 6–8 ч. Событий вроде метеорита нет |
| Анимация | дым из трубы, мерцание окна и фонаря, рябь их отражений, блики на воде: кадры по пиксельной сетке |
| Параллакс | вся картинка мягко плывёт за курсором (камера SceneWall) |
| Музыка | бас: окно и его отражение раздуваются, от окна по пейзажу идёт волна; снейр: вспыхивает фонарь. Встроенные эффекты ЭЛТ (расслоение цветов, «дыхание» краёв) выключены |
| Нагрузка | шелл 241 тик за 10 с против 291 на обоях 2004 (с музыкой) |

Настройки музыки лежат не в сцене, а в `settings.json` angelOS (`wallpaper.perWall`), их пишет `install.sh walls`.

## Как сделать новые обои

Инструменты в `tools/`, исходники «Тихой гавани» в `tools/tihaya-gavan-src/`.

1. **Картинка.** Промпт по образцу `tools/p-day.txt`, референсы: палитра `palette-ref.png` и любой пиксельный пейзаж angelOS как пример стиля. Запуск в отдельной папке, вариантов 2–3:

   ```
   codex exec --skip-git-repo-check -s workspace-write "$(cat p.txt)" -i style-ref.png -i palette-ref.png </dev/null
   ```

2. **Честный пиксель-арт.** `clean.py raw.png day-art.png 320 180 64`: режет картинку Codex на сетку (у Codex пиксель ~5.8 px) и сжимает палитру. Акцентные цвета (окна, огни) резервируются отдельно, иначе их съедает небо.
3. **Сцена.** Увеличить в 12 раз без сглаживания и отдать скрипту автора: `wall-studio.py new картинка.png ~/Pictures/Celestia --mode art`.
4. **Анимация.** `sprites.py <сцена>`. Координаты окна, фонаря, трубы и воды в нём подобраны под «Тихую гавань», для новой сцены их надо мерить заново (по сетке с подписями, см. историю этого файла).
5. **Ночь.** Codex рисует то же место ночью (`p-night.txt`, на вход дневная картинка), `clean.py` её чистит, `night-bake.py <сцена> night-art.png` перекрашивает каждый слой по ночным цветам, переносит луну и раскладывает звёзды. Это скрипт ночи автора без метеорита. Силуэт гор для маски неба обводится руками (`RIDGE` в скрипте): пастельную дымку не отличить от неба ни по яркости, ни по оттенку.
6. **Сумерки и рассвет.** Скрипт автора как есть: `scene-twilight.py <сцена>`.
7. **Музыка.** Модификаторы в `scene.json` → `modifiers` (bulge и wave), встроенные эффекты в `wallpaper.perWall` настроек.

## Грабли

- Слой с `role: "screen"` шейдер рисует как экран ЭЛТ (вспышка, сбой сигнала, радуга). Для окон и огней нужна `role: "light"`.
- Волна на первых ударах песни (`hype`) даёт красно-синий фронт. Это фирменный эффект angelOS, убрать его можно только правкой шейдера автора.
- Черновики в `~/Pictures` не класть: angelOS показывает в списке обоев каждую картинку на глубину до трёх папок.
